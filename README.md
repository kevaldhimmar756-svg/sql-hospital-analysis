## Hospital Data SQL Analysis

**Tools Used:** PostgreSQL, SQL

**About the Project:**
Analysed a hospital database to extract key operational and financial 
insights using SQL queries. This was an independent assignment completed 
as part of the 30-Day SQL Micro Course by Satish Dhawale, Skill Course.

**Key Insights:**
- Total patients across all hospitals
- Top 3 departments with highest patient count
- Hospital with maximum medical expenses
- Longest patient stay analysis
- Monthly medical expenses report
- Average length of stay per department

**Skills Demonstrated:**
SELECT, WHERE, GROUP BY, ORDER BY, AGGREGATE FUNCTIONS, 
DATE FUNCTIONS, TO_CHAR, DATE_TRUNC, SUBQUERIES
